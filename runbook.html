THE RUNBOOK 02—04

Build first.
Auth second.

The site does not need login to exist. Keep the build moving while approval stays a single, deliberate step.

  1. 01

    Build the surface

    Start locally. Confirm the page has real content before touching auth.

    DONE
  2. 02

    Authorize once

    Request developer:manage_builds, domain:read, domain:manage, and developer:update_app together.

    ONE-TIME
  3. 03

    Save the rotation

    Refresh tokens rotate. Re-save after every refresh; never hardcode a secret.

    SAFE
  4. 04

    Deploy to the owner

    Use the app that already owns the domain, then verify with HTTP 200 and real lineup content.

    VERIFY
